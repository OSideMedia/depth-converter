Finished depth motion kits land here, one folder per kit.

Open INDEX.txt for the list, or any kit folder README.txt for what to do with it.

From every kit you take exactly ONE file to OSIDE:
    depth.mp4     upload as the VIDEO reference. That is the whole handover.

Type NO binding phrase in OSIDE, on either path. Uploading depth.mp4 by hand, an uploaded
video ref has no binding field there and the Composer writes its own line (verified on the
live run, 2026-07-25). Coming in through OSIDE's "Import kit" door — merged 2026-09-15 —
you point it at the kit folder and that door fills the field from binding.txt itself,
hash-checked against kit.json; depth.mp4 is still the only file that uploads.

binding.txt is for surfaces that HAVE a per-reference binding field — that door, and the
Ark console block is Variant B in prompt.txt. Everything else in a kit folder is reference
or archive, not for upload.
